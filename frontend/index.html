See which threads fight over a core

HT-Compass predicts how much threads slow each other down when they share a physical core, then chooses the pairing that hurts least. This page shows its report.

Load a report

  1. Compile your program: ./htcompiler prog.c --json prog.htmeta.json -o prog_gen.c
  2. Drop prog.htmeta.json on this page. Add prog_gen.c to see the generated code too.

Manual alternative: ask any chat AI yourself (optional)

The compiler finds opportunities by itself. You can also ask any chat AI for suggestions: copy the prompt, paste the reply below, and run again. Suggestions are only tried first; the compiler still proves each one safe and tests it, so a wrong suggestion is simply rejected.
